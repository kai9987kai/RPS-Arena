# RPS Arena

A polished Rock Paper Scissors desktop game built with Python and Tkinter.

## Features

- Quick Play, Best of 3, and Best of 5 match modes
- Casual and adaptive computer opponents
- Session record, win rate, streaks, and round history
- Keyboard shortcuts and responsive match controls
- JSON statistics export
- Automated tests for the game rules and state transitions

## Run

```powershell
python "RPS NEA MOCK.py"
```

Use the on-screen buttons or press `R`, `P`, or `S`. Press `Ctrl+N` to begin a
new match while retaining session statistics.

## Test

```powershell
python -m unittest -v
```
